unimelb library website usability evaluation

july 2025 - october 2025 ux research user testing

overview

a comprehensive research project evaluating the usability of the university of melbourne's library website. the study involved conducting heuristic evaluations, user testing sessions, thematic analysis of findings, and developing actionable recommendations for improving the user experience.

this project demonstrated strong research methodologies and critical analysis skills, combining quantitative and qualitative research methods to provide a thorough evaluation of the platform's usability.

methodology

the project utilized multiple ux research methods including heuristic evaluation based on nielsen's usability principles, moderated user testing sessions, thematic analysis of user feedback, and affinity mapping to synthesize findings.

tools & skills

ux research, user testing, heuristic evaluation, thematic analysis, affinity mapping, qualitative analysis
